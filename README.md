# Algora

Σύγχρονο, δωρεάν και ανοικτού κώδικα εκπαιδευτικό περιβάλλον για τη ΓΛΩΣΣΑ και την αλγοριθμική.

## v0.1.0-alpha.1
Η πρώτη έκδοση θεμελιώνει το Windows desktop UI και τον πυρήνα του interpreter.

### Στόχος
- editor ΓΛΩΣΣΑΣ
- εκτέλεση και console
- Light / Dark mode
- F11 fullscreen
- lexer → parser → AST → runtime
- μελλοντικά: step execution, πίνακες τιμών, διαγράμματα ροής και debugger

> Το Algora είναι ανεξάρτητο εκπαιδευτικό project και δεν αποτελεί αντίγραφο ή διανομή άλλου διερμηνευτή.
